# AI Code Review Agent

## Problem Statement
Code review is slow and inconsistent. Generic linters miss team-specific coding patterns and recurring mistakes.

## Solution
An AI-powered code review agent that analyzes code, tracks review history, identifies recurring issues, and generates personalized recommendations.

## Features
- AI Code Review
- Multi-language Support
- Review History
- Recurring Issue Detection
- Personalized Recommendations
- JWT Authentication
- Admin Dashboard
- PDF Export

## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- MongoDB
- Groq AI

## Architecture
Frontend → Spring Boot API → Groq AI → MongoDB

## Future Improvements
- Team-wide coding standards learning
- GitHub Integration
- Pull Request Reviews
